# 文字起こし

PC のブラウザで使う文字起こしアプリ。大学の授業・課題用。
OpenAI の Whisper API で文字にし、YouTube の文字起こし欄のように時刻つきの一覧で見られる。

## できること

- **マイク** … 話した声を、数秒ごとに区切ってリアルタイムで文字にする
- **画面・タブの音声** … Zoom・Teams・YouTube など、PC で流れている音声をそのまま文字にする
- **ファイル** … 録音・動画ファイル（mp3 / m4a / wav / mp4 / webm など）を読み込んで文字にする。25MB を超えるファイルはブラウザの中で 10 分ずつに分けて送る
- 時刻つきの一覧表示、検索、1 行ずつ／まとめてコピー、`.txt` 保存
- 行をクリックすると、その場で文字を直せる
- ファイルの場合は、時刻をクリックするとその場面から再生する
- 履歴はブラウザに保存される

## 使い方

1. `index.html` を Chrome か Edge で開く（GitHub Pages で公開してもよい）
2. 「設定」で OpenAI の API キーを入れる（https://platform.openai.com/api-keys で作成）
3. マイク／画面・タブの音声／ファイルのどれかを選んで始める

画面の音声を使うときは、共有するタブを選ぶ画面で **「タブの音声も共有する」をオン** にする。

## 料金のめやす

Whisper API（`whisper-1`）は音声 1 分あたり約 0.006 ドル。90 分の授業で約 0.54 ドル（1 ドル 150 円なら約 80 円）。
無音の区間は送らないので、実際はもう少し安くなる。最新の料金は OpenAI の料金ページで確認すること。

## 注意

- API キーは、使っているブラウザの中（localStorage）だけに保存される。**キーをこのリポジトリに書き込まないこと**
- 文字起こしの履歴もブラウザの中にだけ保存される。別の PC やブラウザとは共有されない
- 授業を録音・文字起こしするときは、大学や先生のルールに従うこと
